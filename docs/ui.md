# 界面与交互

这篇说明悬译的界面是怎么分层的、每个页面为什么这样排、状态怎么表达，以及哪些动效是故意加的。改界面前先读它，改完把这里同步更新。

## 目标

- 一个常驻桌面的小工具，不是仪表盘：打开就能翻，翻完就走。
- 主窗口里只放三件事：**翻译**、**历史**、**设置**；悬停翻译是全局开关，不藏在某一页里。
- 全部颜色、圆角、间距、字号来自 TKCode.Arc 设计令牌，明暗主题、强调色、动效强度改一处、全应用跟着变。
- 界面线程只做界面：翻译、OCR、模型加载都在后台，进度用 `IProgress` 回到 UI 线程。

## 信息架构

```
MainWindow
└── MainView（壳）
    ├── Sidebar           翻译 / 历史 / 设置，底部注明「全程本地运行」
    ├── 顶栏              当前页标题+副标题 · 模型状态 · 悬停取词开关 · 明暗切换
    └── TransitioningContentControl
        ├── TranslatePage   语言对 · 原文卡片 · 译文卡片
        ├── HistoryPage     搜索 · 记录列表 · 空状态
        └── SettingsPage    分组设置 + 底部保存条
HoverWindow                悬停浮窗：原文、译文、状态，一个卡片
```

页面在第一次显示时创建、之后一直保留（滚动位置、输入内容、列表都在）；切页用 180 ms 淡入，侧栏折叠时右侧内容随 `Sidebar.PageShift` 一起滑。

## 翻译页

```
[源语言 ▾] [⇄] [目标语言 ▾] [✓ 意译]        Ctrl+Enter 翻译 · Ctrl+V 粘贴图片
┌ 原文 ──────────────────────┐  ┌ 译文 ──────────────────────────┐
│ 标题行：原文 · 字数 · 清空   │  │ 标题行：译文 · 用时 · 复制 · 重译 │
│ （图片预览条，载入时出现）   │  │ （进行中：顶部 2px 进度条）      │
│ 无边框大字号输入区           │  │ 流式译文 / 骨架行 / 空状态        │
│ 底部：粘贴图片 选择图片 翻译 │  │ 底部：状态行 + 脉冲点            │
└────────────────────────────┘  └────────────────────────────────┘
```

- 语言对放在两栏上方：它是每次翻译都会动的控件。⇄ 每次按下转半圈，并把源/目标互换；源语言是「自动检测」时，换过来后目标落到中文或英语。
- 「意译」紧挨语言对右侧：不勾选按字面直译（默认，适合取词、标签、合同），勾选后按意思译——口语化、口气和俚语跟着地道化。它改的是下一次翻译的指令，不改模型；勾选状态会记住，悬停浮窗始终直译。
- 原文卡片本身是输入区：边框由卡片承担，输入框无边框、18 px、行高舒展（`arc:Textarea`，不是原生 `TextBox`，见文末约束）；输入框**填满卡片留给它的整块高度**（`FrameHeight` 随卡片尺寸在代码里跟着设，所以框下方不会留空白），文字超过可视高度就在框内滚动，贴 200 行也不会把页面撑出窗口；只设 `MaxHeight`/`MaxLines` 都不对——前者只截断不滚动，后者会在框下留空白；译文卡同样在卡内滚动；整张卡片接受拖入图片，拖拽时覆盖一层强调色提示。
- 一个主动作：「翻译」。忙时按钮保持宽度并显示加载态，旁边出现「取消」；`Esc` 同样取消。
- 译文卡按阶段换三副面孔：等首个 token 时是骨架行，流式时是实时文本，结束显示用时。空状态只解释一次「译文会显示在这里」。
- 图片先 OCR 再翻译：粘贴、拖入或选择图片后立刻识别，把文字填进原文并直接开翻，不用再点一次「翻译」；识别不到文字时保留预览条并说明原因。
- 译文是可选中文本（`SelectableTextBlock`）：可以拖选任意一段，右键复制或 `Ctrl+C`；右上角「复制」一键复制全文，点击就地变成「已复制」，不需要弹窗。

## 悬停浮窗

```
┌ 悬译 · 悬停翻译              [进度] [复制] [打开主窗口] [×] ┐
│ 原文（最多三行）                                          │
│ ──────────────────────────────────────────────────────── │
│ 译文（可选中的文本：可 Ctrl+C，长了内部滚动）             │
│ 状态行：正在翻译… / 翻译完成 / 错误原因                    │
└──────────────────────────────────────────────────────────┘
```

- `×` 只收起浮窗，不退出程序；鼠标停在浮窗上时自动隐藏会暂停，方便选中和复制。
- 「打开主窗口」把主窗口显示并激活（最小化时先还原），然后收起浮窗。
- 浮窗不抢焦点：窗口带 `WS_EX_NOACTIVATE`，出现在光标旁也不会把键盘从正在打字的窗口拿走；回到主窗口时浮窗自动收起，不会盖住输入框吃掉点击和按键。需要选中文字时点一下即可，选中后 `Ctrl+C` 复制。

## 历史页

- 搜索框按原文或译文过滤，输入即筛。
- 一行 = 原文（最多两行）+ 译文（最多两行）+ 语言对/时间/图片来源；右侧操作默认半透明，悬停整行上浮 2 px 并点亮。
- 操作：复制译文、放回翻译页重译、删除。清空历史需要再点一次确认，5 秒后自动取消确认态。
- 同一段文字翻译到同一语言只保留最新一条；最多 120 条。
- 空库和「搜不到」是两个不同的空状态，前者给「去翻译」。

## 设置页

三组卡片 + 关于（无卡片），底部常驻保存条：

| 分组 | 内容 | 生效时机 |
| --- | --- | --- |
| 本地模型 | 推理后端（自动/仅 CPU/显卡）、闲置释放内存（0–120 分钟，0 为常驻）、当前模型状态与「立即释放」 | 后端保存后下次启动；闲置时长与「立即释放」马上生效 |
| 悬停取词 | 开关、触发延迟（200–1500 ms） | 立即 |
| 外观 | 主题（跟随系统/浅色/深色）、强调色（8 个预设）、动效（完整/减弱/关闭） | 立即 |
| 关于 | 版本、数据目录（可打开）、MIT 开源说明 | — |

保存条只服务模型组：后端和闲置时长是启动时读的，别的设置都即时生效。状态文字用 `Danger` 令牌表示打不开目录之类的问题。模型没有可选路径和端口——它在进程内，权重随应用分发；显卡后端加载失败会自动回退到 CPU，并在状态行说明。

## 状态与文案

| 状态 | 表达 |
| --- | --- |
| 模型未加载 | 顶栏胶囊「模型按需加载」+ 灰点，悬停提示完整状态 |
| 模型加载中/已加载 | 同一胶囊换成「模型已加载」+ 绿点（`Success`） |
| 翻译中 | 进度条 + 脉冲点 + 状态行；译文区先骨架 |
| 失败 | 状态行改 `Danger` 色，文案说明怎么修（例如换一张更清晰的图） |
| 取消 | 状态行「已取消」，已出现的部分译文保留 |
| 空/无结果 | Arc `EmptyState`，一句话解释 + 一个动作 |

文案规则：句子式中文，按钮是动词（「翻译」「复制」「保存设置」），不用「确定/提交」；错误说怎么改。

## 动效

只做解释变化用的动效，时长都在 160–260 ms：

| 位置 | 动效 | 目的 |
| --- | --- | --- |
| 侧栏 | Arc 弹簧展开/折叠到 64 px 图标栏，选中块滑行 | 层级与当前位置 |
| 页面切换 | `CrossFade` 180 ms | 知道换了一页，不打断 |
| 主题切换 | `ThemeSwitcher` 的 Reveal 过渡 | 明暗切换有来源 |
| 语言交换 | 图标旋转 180° | 两个语言换了位置 |
| 历史行 | 悬停上浮 2 px、操作区 0.55→1 | 这一行可以动 |
| 翻译中 | 2 px 不定进度条 + 强调色脉冲点 | 正在工作，不遮文字 |
| 首个 token 前 | Arc `Skeleton` | 位置先占住，避免跳动 |
| 复制 | `CopyButton` 就地变「已复制」 | 确认，不弹窗 |
| 拖入图片 | 整卡强调色描边 + 「松开…」 | 松手会发生什么 |
| 悬停浮窗 | 160 ms 淡入 + 8 px 上浮 | 从鼠标处出现 |

设置里的「动效 → 减弱/关闭」会传给 Arc 主题；悬停浮窗的入场在减弱/关闭时直接出现，脉冲点和图标旋转这类 300 ms 以内的提示保留。

## 无障碍与键盘

- 图标按钮都有 `AutomationProperties.Name`；侧栏有导航名；控件用 Arc 自带的焦点环。
- `Ctrl+Enter` 翻译，`Esc` 取消；`Ctrl+B` 在侧栏内折叠侧栏；侧栏方向键按 WAI-ARIA tree 模型走。
- 状态不只靠颜色：模型状态有文字，错误有文案，图片记录有「图片」徽标。

## 已知约束 / 下一步

- 窗口用系统标题栏；自绘标题栏能把顶栏和侧栏接成一体，但要自己处理拖动、双击最大化、贴边分屏，等 MVP 后再评估。
- 托盘菜单、全局快捷键、开机启动还没做，设置页里不出现没实现的项。
- 窄到 1040 px 以下不保证布局；再窄需要把语言对和操作行改成换行或图标化。
- 截图只做过程校验（headless 渲染 + 布局断言），没有像素级视觉回归；改视觉时请同时跑一遍明暗两套截图。
- 不要用 Avalonia 原生的 `TextBox`：Arc 主题不为它提供 `ControlTheme`，它照样收键、照样占焦点，却一个像素都不画（输入框、译文都曾因此看起来是空的）。输入用 `arc:Textarea`（多行）或 `arc:Input`，只读文本用 `SelectableTextBlock`；`TranslatePageLayoutTests` 会拦住回退。
